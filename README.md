# Nstyle - Social Platform for Nail Art Enthusiasts

A modern social media platform designed specifically for nail art lovers, salons, and beauty professionals.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Nstyle-io/nstyle-io-2.0.git
cd nstyle-io-2.0

# Install frontend dependencies
cd frontend
npm install

# Start development server
npm run dev
```

## 📁 Project Structure

## ✨ Features

- **Google Maps Integration** - Discover nail salons near you with interactive map
- **Live Search** - Real-time search for salons, users, and hashtags
- **Social Features** - Share nail art, follow users, and engage with the community
- **Responsive Design** - Beautiful dark theme that works on all devices
- **Authentication** - Secure login with Supabase
- **Salon Discovery** - Find and explore nail salons with reviews and ratings
